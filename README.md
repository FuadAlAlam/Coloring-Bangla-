# Coloring: রঙিন গণিত

কম্বিনেটরিক্সের মজার দুনিয়ায় অন্যতম আকর্ষণীয় ও শক্তিশালী একটি টেকনিক হলো **কালারিং**। এই হ্যান্ডআউটে কালারিং টেকনিকের মৌলিক ধারণা থেকে শুরু করে জাতীয় ও আন্তর্জাতিক অলিম্পিয়াড পর্যায়ের বিভিন্ন জটিল সমস্যার সমাধানের পদ্ধতি বিস্তারিতভাবে আলোচনা করা হয়েছে।

## 🛠️ Compilation Guide

এই ডকুমেন্টটি বাংলায় লেখার জন্য `latexbangla` প্যাকেজ এবং ফন্ট রেন্ডারিংয়ের জন্য **XeLaTeX** ইঞ্জিন ব্যবহার করা হয়েছে।

### Prerequisites:
- **TeX Distribution**: TeX Live / MacTeX / MiKTeX
- **TeX Engine**: `xelatex`
- **Fonts**: [Kalpurush](Kalpurush), [SiyamRupali](SiyamRupali), [SolaimanLipi](SolaimanLipi)

### টার্মিনাল থেকে কম্পাইল করার নিয়ম:
```bash
xelatex main.tex
```
